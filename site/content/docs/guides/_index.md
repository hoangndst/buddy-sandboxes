# Guides

Practical guides for configuring and operating Buddy Sandboxes across common agent workflows.

## Available Guides

- **Configuring Network Isolation**: Restricting outbound network traffic, whitelisting LLM API domains, and enabling egress proxying.
- **Persistent Agent Workspaces**: Mounting PersistentVolumeClaims and configuring automatic Git repository cloning.
- **Supervisor Sessions**: Attaching, detaching, and streaming stdout/stderr from background agent tasks using `buddy-sbx attach`.
- **Warm Runner Pools**: Configuring minimum standby replicas and scaling limits for instant agent invocation.
- **Suspension and Resumption**: Preserving workspace state and freeing cluster compute resources when agents go idle.
