# Buddy Sandboxes Documentation

Buddy Sandboxes provides Kubernetes-native sandboxing for AI coding agents. Run untrusted agent workloads with hardware or container isolation, network egress boundaries, and credential brokering where API keys never enter the execution container.

## Documentation Sections

- [Getting Started](./getting-started/): Prerequisites, local cluster setup, operator installation, and creating your first sandbox.
- [Concepts](./concepts/): Core architectural concepts including sandbox pods, warm pooling, network isolation levels, and storage lifecycles.
- [Guides](./guides/): Operational guides for configuring network profiles, attaching interactive supervisor sessions, and setting up persistent workspaces.
- [Reference](./reference/): Complete reference documentation for the `buddy-sbx` CLI and Kubernetes Custom Resource Definitions (CRDs).
